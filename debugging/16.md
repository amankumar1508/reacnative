# 🛠 Debugging Tools

| Tool | Purpose |
|------|---------|
| React Native DevTools | Debug JavaScript |
| Console | Print logs |
| Network Panel | Inspect API requests |
| Profiler | Find performance issues |
| Xcode | Debug iOS native issues |
| ADB Logcat | Debug Android native issues |
| Sentry | Monitor production crashes |

---

# 💻 Useful Commands

### Start Expo

```bash
npx expo start
```

### Clear Metro Cache

```bash
npx expo start -c
```

### Run in Production Mode

```bash
npx expo start --no-dev --minify
```

### Generate Native Projects

```bash
npx expo prebuild
```

### Generate Only iOS

```bash
npx expo prebuild -p ios
```

### Generate Only Android

```bash
npx expo prebuild -p android
```

### Android Logs

```bash
adb logcat
```

### Open iOS Project

```bash
xed ios
```

# ❌ Common Errors

| Error | Solution |
|--------|----------|
| Cannot read property of undefined | Check the value before accessing it |
| Too many re-renders | Avoid updating state during render |
| Maximum update depth exceeded | Fix the `useEffect` dependency array |
| Network request failed | Verify the URL and internet connection |
| Build Failed | Clean and rebuild the project |
| Code Signing Failed | Check Xcode signing settings |

# ⚡ Performance Tips

- Use FlatList for long lists.
- Avoid unnecessary re-renders.
- Memoize expensive components.
- Optimize image sizes.
- Monitor CPU and memory usage.
- Use the React Native Profiler.

---

# 🧹 Common Fixes

Restart Metro:

```bash
npx expo start -c
```

Reinstall packages:

```bash
npm install
```

Install CocoaPods:

```bash
cd ios && pod install
```

Clean Android build:

```bash
cd android && ./gradlew clean
```
