# 📚 Introduction

Imagine you're building a login screen.

The user logs in successfully.

Everything works perfectly.

But after closing and reopening the app...

The user is logged out.

Why?

Because the login information was stored only in **React State**, which is temporary.

When the application closes, React State is destroyed.

To keep data even after the app is closed, React Native provides **persistent storage**.

One of the most commonly used storage solutions is **AsyncStorage**.

Understanding how AsyncStorage works—and more importantly, how to debug it—is essential for every React Native developer.

---

# 🤔 What is AsyncStorage?

AsyncStorage is a simple, asynchronous, persistent key-value storage system for React Native.

Think of it as a small local database for your application.

Instead of storing data on a server, AsyncStorage stores data **on the user's device**.

Examples:

- Login Tokens
- User Information
- Theme Preference
- Language Preference
- App Settings
- Shopping Cart
- Recently Viewed Items

---

# 📦 How Does AsyncStorage Work?

AsyncStorage stores information using a **key-value** format.

Example

```
Key

"user"

↓

Value

"{\"name\":\"Aman\",\"age\":20}"
```

Every piece of data has:

- A Key
- A Value

The key is used to retrieve the stored value later.

---

# ⚠️ Important

AsyncStorage stores **only strings**.

This is one of the biggest reasons beginners encounter bugs.

Example

```javascript
{
   name: "Aman",
   age: 20
}
```

❌ This object **cannot** be stored directly.

Instead:

```javascript
JSON.stringify(user)
```

must be used before saving.

When reading the data back:

```javascript
JSON.parse(user)
```

converts it back into an object.

---

# 🧠 Why Use AsyncStorage?

Without AsyncStorage

```
Open App

↓

Login

↓

Close App

↓

Everything Lost
```

With AsyncStorage

```
Open App

↓

Login

↓

Save Token

↓

Close App

↓

Open Again

↓

User Still Logged In
```

This creates a better user experience.

# ✍️ Saving Data

Example:

```javascript
await AsyncStorage.setItem("username", "Aman");
```

Here:

```
Key

↓

username

Value

↓

Aman
```

The value is saved on the device.

---

# 📖 Reading Data

```javascript
const username = await AsyncStorage.getItem("username");

console.log(username);
```

Output

```
Aman
```

---

# ❌ Bug 1 — Data Disappears After Restart

Many beginners write:

```javascript
const [username, setUsername] = useState("Aman");
```

Everything works...

Until the app closes.

After reopening:

```
username

↓

""
```

---

### 🤔 Why?

React State exists only while the application is running.

When the application closes, the state disappears.

---

### ✅ Solution

Store the value:

```javascript
await AsyncStorage.setItem("username", "Aman");
```

Read it back during app startup.

---

# ❌ Bug 2 — Saving an Object Directly

Example

```javascript
const user = {
    name: "Aman",
    age: 20
};

await AsyncStorage.setItem("user", user);
```

Error

```
AsyncStorage only accepts string values.
```

---

### ✅ Fix

```javascript
await AsyncStorage.setItem(

    "user",

    JSON.stringify(user)

);
```

Now it saves correctly.

---

# ❌ Bug 3 — JSON Parsing Error

Example

```javascript
const user = await AsyncStorage.getItem("user");

console.log(user.name);
```

Output

```
undefined
```

Why?

Because

```
user

↓

String
```

not

```
Object
```

---

### ✅ Fix

```javascript
const user = JSON.parse(

    await AsyncStorage.getItem("user")

);
```

Now

```javascript
console.log(user.name);
```

prints

```
Aman
```

---

# ❌ Bug 4 — Unexpected token u in JSON

Example

```javascript
const user = JSON.parse(

    await AsyncStorage.getItem("user")

);
```

Output

```
Unexpected token u in JSON
```

---

### Why?

The value returned is

```
null
```

or

```
undefined
```

because nothing was saved.

---

### ✅ Fix

```javascript
const value = await AsyncStorage.getItem("user");

if(value){

    const user = JSON.parse(value);

}
```

Always check before parsing.

---

# ❌ Bug 5 — Login Doesn't Persist

User logs in.

Token received.

Everything works.

Restart app.

Back to Login Screen.

---

### Investigation

Check:

```
Token received?

↓

Token saved?

↓

Token loaded?

↓

Navigation updated?
```

The issue may not be AsyncStorage—it could be that the app never reads the saved token on startup.

---

# 🔍 Debugging AsyncStorage

Whenever storage doesn't behave as expected:

Ask yourself:

✅ Was the data saved?

✅ Is the key correct?

✅ Is the value a string?

✅ Did JSON.parse() succeed?

✅ Am I reading the correct key?

✅ Did I await the Promise?

---

# 💡 Best Practices

- Use meaningful keys (`user`, `theme`, `token`).
- Always use `await`.
- Store objects with `JSON.stringify()`.
- Parse objects with `JSON.parse()`.
- Check for `null` before parsing.
- Remove unused data when users log out.

---

# ❌ Common Mistakes

- Forgetting `await`
- Saving objects directly
- Parsing `null`
- Using different keys when saving and reading
- Assuming AsyncStorage updates instantly
- Forgetting to clear data on logout
