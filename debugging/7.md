# 📚 Introduction

React Native applications are built using **components**.

A component is a reusable piece of UI that accepts **props** (properties) from its parent.

When something appears wrong on the screen, the bug often comes from one of these areas:

- The component isn't rendering.
- The parent didn't pass the correct props.
- The child expected different data.
- A prop value is `undefined` or `null`.

Learning to inspect components and props is one of the fastest ways to locate UI bugs.

---

# 🧩 What is a Component?

A component is a reusable building block of a React Native application.

Example:

```jsx
function Welcome() {
  return <Text>Welcome!</Text>;
}
```

You can reuse it anywhere:

```jsx
<Welcome />
```

Components make your application easier to organize and maintain.

---

# 📦 What are Props?

Props (short for **properties**) are values passed from a parent component to a child component.

Example:

```jsx
function Welcome({ name }) {
  return <Text>Welcome {name}</Text>;
}
```

Parent:

```jsx
<Welcome name="Aman" />
```

Output:

```
Welcome Aman
```

Props allow components to be dynamic and reusable.

---

# ❌ Bug 1: Missing Prop

Child Component:

```jsx
function Welcome({ name }) {
  return <Text>{name}</Text>;
}
```

Parent:

```jsx
<Welcome />
```

Output:

```
(blank)
```

Or:

```
undefined
```

### 🔍 How to Debug

1. Open **React Native DevTools**.
2. Go to the **Components** panel.
3. Select the `Welcome` component.
4. Inspect the **Props** section.

You'll notice that `name` is missing.

### ✅ Fix

```jsx
<Welcome name="Aman" />
```

---

# ❌ Bug 2: Wrong Prop Name

Child:

```jsx
function Welcome({ username }) {
  return <Text>{username}</Text>;
}
```

Parent:

```jsx
<Welcome name="Aman" />
```

### Problem

The child expects `username`, but the parent sends `name`.

### Fix

Either change the child:

```jsx
function Welcome({ name }) {
  return <Text>{name}</Text>;
}
```

Or change the parent:

```jsx
<Welcome username="Aman" />
```

---

# ❌ Bug 3: Undefined Object Property

```jsx
function Profile({ user }) {
  return <Text>{user.name}</Text>;
}
```

If `user` is `undefined`, React Native throws:

```
TypeError:
Cannot read property 'name' of undefined
```

### Fix

```jsx
function Profile({ user }) {
  if (!user) {
    return <Text>Loading...</Text>;
  }

  return <Text>{user.name}</Text>;
}
```

# 🔍 Inspecting Components

Open **React Native DevTools**.

Navigate to:

```
Components
```

You'll see a tree similar to:

```
<App>
 ├── Navigation
 │    ├── HomeScreen
 │    └── ProfileScreen
 └── SettingsScreen
```

Click a component to inspect:

- Props
- State
- Hooks

This helps verify whether data is flowing correctly.

# 🎯 Debugging Parent → Child Communication

Parent:

```jsx
const user = {
  name: "Aman",
};

<Profile user={user} />
```

Child:

```jsx
function Profile({ user }) {
  return <Text>{user.name}</Text>;
}
```

If the child doesn't receive the expected data:

- Inspect the parent.
- Confirm the prop exists.
- Verify the prop name matches.
- Inspect the child in DevTools.

---

# ⚠️ Conditional Rendering Issues

Example:

```jsx
{isLoggedIn && <Dashboard />}
```

If `Dashboard` never appears:

Check:

```jsx
console.log(isLoggedIn);
```

Or inspect the component using DevTools to verify the value of `isLoggedIn`.

# 🧪 Real-World Scenario

### Problem

A profile screen displays:

```
Welcome undefined
```

### Investigation

- Open Components panel.
- Select `Profile`.
- Inspect props.

Props show:

```json
{
  "username": "Aman"
}
```

But the component expects:

```jsx
function Profile({ name }) {}
```

### Solution

Update either the parent or child so the prop names match.

---

# 💡 Best Practices

- Keep prop names consistent.
- Validate data before using it.
- Avoid deeply nested props when possible.
- Use optional chaining (`user?.name`) for safer access.
- Inspect props before changing code.

---

# ❌ Common Mistakes

- Misspelled prop names.
- Forgetting to pass required props.
- Assuming data always exists.
- Accessing nested properties without checks.
- Modifying props inside a child component.
