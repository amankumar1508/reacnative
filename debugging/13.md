# 📚 Introduction

Every React Native developer encounters errors.

Some are easy to fix.

Others can take hours if you don't know where to look.

This guide collects the most common React Native errors, explains **why they happen**, and shows **how to fix them quickly**.

---

# 💻 JavaScript Errors

| Error | Cause | Fix |
|--------|-------|-----|
| Cannot read property 'x' of undefined | Variable is `undefined` | Use optional chaining or check before accessing |
| is not a function | Wrong variable type | Verify the function exists |
| Unexpected token | Syntax error | Check brackets, commas, and quotes |
| Maximum call stack exceeded | Infinite recursion | Fix recursive function |

---

# ⚛️ React Errors

| Error | Cause | Fix |
|--------|-------|-----|
| Too many re-renders | State updated during render | Move update into an event or `useEffect` |
| Invalid Hook Call | Hook used incorrectly | Call Hooks only at the top level of a component |
| Maximum update depth exceeded | Infinite `useEffect` loop | Review the dependency array |
| Each child should have a unique key | Missing `key` prop | Add a stable unique key when rendering lists |

---

# 📦 Metro Errors

| Error | Cause | Fix |
|--------|-------|-----|
| Unable to resolve module | Incorrect import path | Check the file path and filename |
| Metro cache issue | Stale cache | `npx expo start -c` |
| Duplicate module | Dependency conflict | Remove duplicates and reinstall packages |

---

# 🚀 Expo Errors

| Error | Cause | Fix |
|--------|-------|-----|
| Expo Go version mismatch | SDK mismatch | Update Expo Go or the project SDK |
| Native module cannot be found | Module not installed | Install the correct Expo package |
| Project incompatible with Expo Go | Native dependency | Create a development build |

---

# 🍎 iOS Errors

| Error | Cause | Fix |
|--------|-------|-----|
| Info.plist permission missing | Missing usage description | Add the required permission key |
| Build failed | Native configuration | Clean and rebuild the project |
| Code Signing Failed | Incorrect signing settings | Configure the correct team/profile |

---

# 🤖 Android Errors

| Error | Cause | Fix |
|--------|-------|-----|
| INSTALL_FAILED_VERSION_DOWNGRADE | Older version installed | Uninstall the app before reinstalling |
| Gradle build failed | Dependency issue | Clean Gradle cache and rebuild |
| Manifest merge failed | Conflicting manifests | Review AndroidManifest.xml changes |

---

# 🌐 Network Errors

| Error | Cause | Fix |
|--------|-------|-----|
| Network request failed | Device offline / wrong URL | Check connectivity and endpoint |
| 401 Unauthorized | Invalid token | Refresh or replace the token |
| 404 Not Found | Wrong endpoint | Verify the API path |
| 500 Internal Server Error | Backend issue | Check server logs |

---

# 🏗 Build Errors

| Error | Cause | Fix |
|--------|-------|-----|
| CocoaPods install failed | Pod issue | `pod install` again |
| Gradle failed | Android build issue | Sync Gradle and rebuild |
| SDK version mismatch | Incompatible versions | Update dependencies |

# 🛠 Common Fixes

Try these before diving deeper:

```bash
npx expo start -c
```

```bash
npm install
```

```bash
pod install
```

```bash
./gradlew clean
```

Restart:

- Metro Bundler
- Simulator / Emulator
- IDE

Many temporary issues disappear after a clean rebuild.

---

# ✅ Debugging Checklist

Before searching online:

- Read the full error message.
- Read the first error, not the last.
- Check the stack trace.
- Verify recent code changes.
- Restart Metro.
- Clear caches.
- Test on another device.
- Search the exact error message.
