# 📚 Introduction

Good developers don't fix bugs by guessing.

They follow a repeatable process.

A debugging workflow helps you:

- Find bugs faster
- Avoid random code changes
- Understand the root cause
- Prevent the same bug from happening again

This repository introduces a practical debugging workflow you can apply to almost any React Native issue.

---

# 🤔 What is a Debugging Workflow?

A debugging workflow is a step-by-step method for identifying, investigating, fixing, and verifying bugs.

Instead of trying random solutions, you work through the problem logically.

---

# 🛠 The 7-Step Debugging Process

## 1️⃣ Understand the Problem

Ask:

- What happened?
- What should have happened?
- Can you reproduce the issue?

---

## 2️⃣ Reproduce the Bug

Try to make the issue happen consistently.

Without reproduction, debugging becomes guesswork.

---

## 3️⃣ Read the Error

Always read:

- Error message
- Stack trace
- Native logs (if applicable)

Don't ignore warnings—they often point to the real issue.

---

## 4️⃣ Isolate the Cause

Reduce the problem to the smallest possible example.

Disable unrelated code if necessary.

The goal is to identify the exact source of the bug.

---

## 5️⃣ Choose the Right Tool

| Problem | Tool |
|---------|------|
| JavaScript error | React Native DevTools |
| Network issue | Network Panel |
| Performance problem | Profiler |
| Android native issue | ADB Logcat |
| iOS native issue | Xcode |
| Production crash | Sentry |

Using the right tool saves time.

---

## 6️⃣ Fix the Root Cause

Avoid quick fixes that only hide the symptom.

Ask yourself:

- Why did this happen?
- Will this fix similar cases?

---

## 7️⃣ Verify the Fix

After applying the fix:

- Test again.
- Check edge cases.
- Ensure no new bugs were introduced.
- Test on Android and iOS if applicable.

# 🌍 Real-World Example

### Problem

The app crashes when opening the Camera screen on iOS.

### Workflow

1. Reproduce the issue.
2. Read Xcode logs.
3. Find missing `NSCameraUsageDescription`.
4. Add the required permission.
5. Rebuild the app.
6. Verify the camera opens successfully.

The key wasn't guessing—it was following a structured process.

# ❌ Common Mistakes

- Changing multiple things at once.
- Ignoring the first error message.
- Skipping logs.
- Fixing symptoms instead of causes.
- Not testing after the fix.

---

# 💡 Best Practices

- Reproduce before fixing.
- Make one change at a time.
- Use version control.
- Keep notes on recurring issues.
- Learn from every bug you solve.
