# 📚 Introduction

Reading about debugging is useful.

Actually **finding and fixing bugs** is what makes you a better developer.

This repository contains hands-on debugging exercises based on real React Native problems.

Each exercise includes:

- 🐞 Problem
- 📋 Description
- 💡 Hint
- ✅ Solution

> **Tip:** Try solving the bug yourself before viewing the solution.

---

# 🟢 Beginner Exercises

## Exercise 1 – RedBox Error

### 🐞 Problem

```jsx
<Text>{user.name}</Text>
```

App crashes with:

```text
Cannot read property 'name' of undefined
```

### 💡 Hint

Check whether `user` exists before accessing `name`.

### ✅ Solution

```jsx
<Text>{user?.name}</Text>
```

---

## Exercise 2 – Infinite Re-render

### 🐞 Problem

```jsx
setCount(count + 1);
```

called during rendering.

### 💡 Hint

State updates should happen inside an event handler or `useEffect`.

---

## Exercise 3 – API Request Failed

### 🐞 Problem

```text
Network request failed
```

### 💡 Hint

Check:

- Internet connection
- API URL
- Emulator/device network
- HTTPS vs HTTP

# 🟡 Intermediate Exercises

## Exercise 4 – App Freezes

Symptoms:

- Slow UI
- High CPU usage

### Goal

Use the **Profiler** to identify unnecessary re-renders.

---

## Exercise 5 – Android Only Crash

The app works on iOS but crashes on Android.

### Goal

Use **ADB Logcat** to identify the native error.

---

## Exercise 6 – iOS Startup Crash

The app closes immediately after launch.

### Goal

Use **Xcode** to inspect the native crash log.

---

# 🔴 Advanced Exercises

## Exercise 7 – Memory Leak

Symptoms:

- Memory usage keeps increasing.
- App becomes slower over time.

### Goal

Use **Memory Graph** to locate unreleased objects.

---

## Exercise 8 – Production Crash

A user reports:

```text
App crashes after login.
```

No development error appears.

### Goal

Use **Sentry** to investigate the crash report.

---

## Exercise 9 – Performance Issue

Symptoms:

- Scrolling is laggy.
- Animations stutter.

### Goal

Find the bottleneck using the **React Native Profiler**.

# 🏆 Debugging Challenges

Challenge yourself by solving these without looking at the solution:

- Blank white screen
- App stuck on splash screen
- Camera crashes only on iOS
- Push notifications not working
- Login state not updating
- Slow FlatList scrolling
- Random production crash
- Memory leak after navigation
- Build failed after installing a package
- App works in Expo Go but not in a development build

---

# 💡 Best Practices

- Read the error message first.
- Reproduce the bug consistently.
- Use the correct debugging tool.
- Fix the root cause.
- Verify the solution.
