# 📚 Introduction

React Native debugging usually starts with:

- React Native DevTools
- Console Logs
- Stack Traces
- Network Panel

However, not every bug comes from JavaScript.

Some bugs occur inside **native iOS code**, where React Native DevTools cannot help.

For those situations, use **Xcode**.

---

# 🤔 What is Xcode?

Xcode is Apple's official IDE for building and debugging iOS applications.

React Native developers use Xcode to:

- Build iOS apps
- Run the iOS Simulator
- Debug native crashes
- Read native logs
- Analyze memory
- Inspect the UI hierarchy

---

# ❓ When Should You Use Xcode?

| Situation | Use Xcode |
|-----------|-----------|
| App crashes on startup | ✅ |
| Camera crashes only on iOS | ✅ |
| Push Notifications fail | ✅ |
| Build Failed | ✅ |
| Memory Leak | ✅ |
| JavaScript Error | ❌ Use RN DevTools |
| API Error | ❌ Use Network Panel |

---

# 🏗 React Native Debugging Architecture

```text
React Native App
        │
 ┌──────┴──────┐
 │             │
 ▼             ▼
JavaScript   Native iOS
 │             │
 ▼             ▼
RN DevTools   Xcode
```

**Rule**

- JavaScript issue → React Native DevTools
- Native iOS issue → Xcode

# ⚙️ Setup

## Install Xcode

Download Xcode from the **Mac App Store**.

Install Command Line Tools:

```bash
xcode-select --install
```

Verify installation:

```bash
xcodebuild -version
```

Generate iOS project:

```bash
npx expo prebuild -p ios
```

Open in Xcode:

```bash
xed ios
```

# 🧠 LLDB

LLDB is Xcode's native debugger.

Use it to:

- Pause execution
- Inspect variables
- Read stack frames
- Execute debugging commands

Example:

```lldb
po variableName
```

# 💥 Debugging Native Crashes

Common causes:

- Missing Permissions
- Invalid Info.plist
- Native Module Failure
- Code Signing Problems
- Missing Frameworks

Read:

- Crash Log
- Stack Trace
- Exception Message

Always fix the **first error** before investigating others.

---

# ❌ Common Errors

| Error | Solution |
|--------|----------|
| Build Failed | Clean Build Folder |
| Framework Not Found | Reinstall Pods |
| Code Signing Failed | Check Signing Settings |
| Missing Info.plist Key | Add Required Permission |
| App Crashes on Launch | Read Native Stack Trace |

---

# 💡 Best Practices

- Use React Native DevTools first.
- Open Xcode only for native issues.
- Read the first error carefully.
- Keep Xcode updated.
- Test on both simulator and real device.
- Clean the build folder after major changes.
- Commit before changing native configuration.
